# Font Pairings — The Vault

Every Surprise Me build MUST use a unique font pairing. Never use the same pairing twice in a session.

All fonts are free on Google Fonts. Load with:
```html
<link href="https://fonts.googleapis.com/css2?family=HEADING+FONT&family=BODY+FONT&display=swap" rel="stylesheet">
```

## How to Pick

1. Roll randomly or pick one that matches the seed's personality
2. Heading font = identity. Body font = readability. They should contrast, not compete.
3. Every pairing is pre-validated to work together. Trust it.

## Anti-Rules

- NEVER use the same pairing twice in a session
- NEVER use Inter for both heading AND body (lazy)
- NEVER use more than 2 fonts on one page
- NEVER use a heading font for body text (or vice versa)
- Heading weight must be 700+. Body stays 400-500.
