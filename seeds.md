# The Seed Vault — Creative Prompts for Random Builds

When a user says "surprise me", "show me what you got", "build something cool", or gives no direction — use this vault.

## How It Works

1. **Pick a seed** — roll randomly or pick one that excites you. Never reuse the same seed twice.
2. **Amplify it** — the seed is a starting point. Add specificity. Invent a brand name, a tagline, real copy.
3. **Build it** — full page, HTML+CDN Tailwind, using the youeye principles.

## The Formula (for generating your own seeds)

Every great website concept combines:

```
[Surprising subject] × [Unusual audience] × [Strong personality] × [Specific constraint]
```

Bad: "A SaaS landing page" — generic, no soul
Good: "A dark, cinematic page for a fictional company that maps whale migration routes using sound"

## Roll Rules

- Never pick seed #1 twice in a row
- When you pick a seed, **amplify it** — add a fictional brand name, a real tagline, 3 features, a target audience
- The seed is the CONCEPT. The youeye anti-slop checklist is the QUALITY gate
- Every build must pass the Gold Standard Test: squint → still see hierarchy? Ship it
